关于本站

一个切口，三个层面

“文明交流互鉴”容易写成宏大的口号。本站选择“听障”这个具体切口，是因为它足够小， 能让事实站得住；又足够深，能穿过教育、医疗与学术三个层面。

全站围绕三个关键词组织：包容（教育从隔离走向融合）、全链条（医疗从单次手术走向能力建设）、 适配（知识与标准从直接移植走向文化重构）。它们共同回答一个问题： 当善意跨越国界，什么样的交流才称得上“互鉴”。

AI 辅助使用声明

AI 做了什么，
没做什么

本站使用了 AI 工具辅助完成部分工作，按课程要求如实说明如下。

  • 参与的部分：资料检索与外文文献摘要的初步翻译、文案结构建议与润色、HTML/CSS/JS 代码的编写与调试辅助。
  • 未参与的部分：选题与核心论点、案例取舍、对事实的最终核对、页面设计决策与最终定稿判断。
  • 核实方式：文中每个数字、日期、人名与机构名，均逐条回到参考文献原文核对；无法核实的细节一律不写。
关于图表数据：页面 C 的柱状图只使用文献中明确给出的比例数据（23.1% / 81.4%）。 对于以组间差异报告、未给出并列均值的研究，本站不虚构柱高，改用表格呈现结论。
关于“表述红线”：纪录片名为《校长的心愿》（Hands of Hope），不写作“《希望之手》纪录片”； 苏帕潘的身份为老挝民办听障儿童学校创办人 / 校长；David 案例时间为 2026 年 7 月，主刀医生黄益灯； 乌兹别克斯坦援助为 2025 年 2 月，医生刘玉和。

素材与版权

没有一张来路不明的图片

为避免版权风险，本站不使用新闻机构的原始配图，全部视觉元素均为自制。

图形

首页声波涟漪、装饰圆点与图标，全部为手写 SVG 路径，随页面加载，无外部图片请求。

字体

仅使用系统字体栈（苹方 / 微软雅黑 / system-ui），不加载任何网络字体，既快也没有授权问题。

图表

图表由本站依据已核实数据用 ECharts 绘制；同时提供完整数据表格，无 JS 时仍可读到全部数值。

技术说明

用了什么，为什么用它

不依赖重型框架：首屏不需要等待任何 JS 就能读完。

表 3 · 技术选型与理由
技术用在哪里为什么
CSS Grid首页卡片、对照表、整体栅格二维布局，代码量比浮动/弹性更少
Flexbox页面 A 双栏对照、导航与页脚一维对齐与换行，天然适配不同内容长度
媒体查询960px / 640px 两档断点桌面、平板、手机三档；时间线在窄屏转纵向
IntersectionObserver时间线逐级高亮、滚动入场比监听 scroll 计算位置更省性能
原生 JS 标签页页面 B / C 的对照切换无需引入组件库，保留键盘操作与 ARIA 状态
ECharts（CDN）仅页面 C 的一个图表按需加载，失败时自动降级为数据表

可访问性

  • 语义化标签：header / nav / main / article / footer
  • 跳转链接、焦点样式、aria-current 与 aria-selected
  • 图片与图形均有替代文本或标注为装饰
  • 尊重 prefers-reduced-motion，关闭动效
